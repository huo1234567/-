**功能描述**
为搜索系统增加查询历史功能，包括"撤销上一次查询"和"最近 10 次查询记录"两项。
**功能要求**
1. 实现两个数据结构类：撤销栈 `UndoStack` 与历史队列 `HistoryQueue`。
2. 两个类必须自行实现。禁止直接将 Python 的 `list` 用作栈或队列，亦不允许使用 `collections.deque`。
3. **撤销栈 `UndoStack` 严格行为定义**：
执行一次新的搜索就将搜索词压入栈顶.
调用 `undo()` 时栈非空就弹出栈顶元素；若弹栈后栈仍非空，使用新栈顶的词重新执行一次搜索（该次搜索**不重新压栈**）并返回结果；若弹栈后栈为空，返回空结果.
调用 `undo()` 时栈本就为空就返回空结果，不报错，不修改栈.
4. **历史队列 `HistoryQueue` 严格行为定义**：
   - 容量上限为 10。每次执行新的搜索后，将搜索词入队。
   - 队列已满时，新元素入队会自动使最老元素出队。
   - 提供 `recent()` 方法，返回当前队列中的所有元素，按入队时间从早到晚排列。
**撤销栈示例**
依次搜索 A、B、C，栈状态为 `[A, B, C]`（C 在栈顶）：
| 步骤 | 操作       | 栈状态     | 返回结果                   |
| ---- | ---------- | ---------- | -------------------------- |
| 1    | `undo()` | `[A, B]` | B 的搜索结果               |
| 2    | `undo()` | `[A]`    | A 的搜索结果               |
| 3    | `undo()` | `[]`     | 空结果                     |
| 4    | `undo()` | `[]`     | 空结果（栈本就空，不报错） |

class UndoStack:
    def __init__(self):
        self.stack = []
        self.top = -1  # 栈顶指针，自行实现栈结构
    def push(self, item):
        # 压栈：栈顶+1，存入元素
        self.top += 1
        self.stack.append(item)
    def pop(self):
        # 弹栈：栈非空则弹出栈顶
        if self.top < 0:
            return None
        item = self.stack[self.top]
        del self.stack[self.top]
        self.top -= 1
        return item
    def peek(self):
        # 查看栈顶，不弹出
        if self.top < 0:
            return None
        return self.stack[self.top]
    def is_empty(self):
        return self.top < 0
# ==================== 功能3：自定义数据结构 - 历史队列 ====================
class HistoryQueue:
    def __init__(self, capacity=10):
        self.queue = []
        self.capacity = capacity
        self.front = 0  # 队首指针
        self.rear = 0   # 队尾指针
    def enqueue(self, item):
        # 入队：满了则先移除队首
        if len(self.queue) >= self.capacity:
            self.dequeue()
        self.queue.append(item)
        self.rear += 1
    def dequeue(self):
        # 出队：移除队首
        if self.front >= self.rear:
            return None
        item = self.queue[self.front]
        del self.queue[self.front]
        self.rear -= 1
        return item
    def recent(self):
        # 返回所有历史，早 → 晚
        return self.queue.copy()
