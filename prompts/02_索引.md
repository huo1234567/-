A1:功能二:倒排索引
**功能描述**
基于必做功能 1 的切词结果，建立倒排索引。倒排索引记录每个词项出现于哪些文档中，使关键词查询的时间复杂度降至常数级。
**功能要求**
1. 必须使用哈希表（Python 中的 `dict`）实现倒排索引，禁止使用列表（list）作为主存储结构。
2. 索引结构：
   - key：词项（字符串），即必做功能 1 切出的单字、单词或数字串。
   - value：包含该词项的文档编号列表。同一篇文档对同一词项只记录一次（即使该词项在该篇中重复出现）。
   - value 列表中的文档编号按升序排列。
3. 提供查询接口 `search(word)`：
   - 输入约定：`word` 须为单个词项（单个汉字、单个英文小写单词或单个数字串）。
   - 多字符复合查询（如同时输入"算法"两个汉字）不在本功能要求范围内，属于选做功能 6 的扩展。
   - 英文输入须先统一转换为小写后再查找。
   - 输出：包含 `word` 的文档编号列表（已升序）。
**查询示例**
text
search("算")        → [0, 2, 4]
search("algorithm") → [1, 3]
search("Algorithm") → [1, 3]            （等价于 search("algorithm")）
search("2026")      → [5]
search("鲸")        → []                （未出现的词项）
search("")          → []                （空字符串）

**验收标准**
1. `search(w)` 对所有出现于 testdata 的词项，返回正确的文档编号列表。
2. `search(w)` 对未出现于 testdata 的词项，返回空列表 `[]`。
3. `search("")`（空字符串）返回空列表 `[]`。
4. `search` 对英文输入大小写不敏感（自动转小写）。
5. 索引中每个 value 列表内无重复元素，且按文档编号升序排列。
6. 索引使用 dict 实现。

import os
def tokenize_text(text: str) -> list[str]:
    tokens = []
    current_buffer = []
    text = text.lower()
    for char in text:
        is_chinese = '\u4e00 <= char <= \u9fff'
        is_letter = char.isalpha()
        is_digit = char.isdigit()
        if is_chinese:
            if current_buffer:
                tokens.append(''.join(current_buffer))
                current_buffer.clear()
            tokens.append(char)
        elif is_letter or is_digit:
            current_buffer.append(char)
        else:
            if current_buffer:
                tokens.append(''.join(current_buffer))
                current_buffer.clear()
    if current_buffer:
        tokens.append(''.join(current_buffer))
    return tokens
def load_and_tokenize(folder_path: str) -> dict[int, list[str]]:
    txt_files = [f for f in os.listdir(folder_path) if f.endswith('.txt')]
    txt_files.sort()
    doc_tokens = {}
    for idx, filename in enumerate(txt_files):
        file_path = os.path.join(folder_path, filename)
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                content = f.read()
            tokens = tokenize_text(content)
            doc_tokens[idx] = tokens
        except Exception as e:
            print(f"读取文件 {filename} 失败：{str(e)}")
            doc_tokens[idx] = []
    return doc_tokens
def build_inverted_index(doc_tokens: dict[int, list[str]]) -> dict[str, list[int]]:
    """
    构建倒排索引（哈希表dict实现）
    :param doc_tokens: 切词后的文档字典
    :return: 倒排索引 {词项: [升序排列的文档编号列表]}
    """
    inverted_index = {}
    for doc_id, tokens in doc_tokens.items():
        # 对当前文档去重，保证同一词项只记录一次
        unique_tokens = set(tokens)
        for word in unique_tokens:
            if word not in inverted_index:
                inverted_index[word] = []
            if doc_id not in inverted_index[word]:
                inverted_index[word].append(doc_id)
                inverted_index[word].sort()  # 保持升序
    return inverted_index
def search(word: str, inverted_index: dict[str, list[int]]) -> list[int]:
    """
    倒排索引查询接口（大小写不敏感，自动转小写）
    :param word: 单个词项
    :param inverted_index: 倒排索引
    :return: 升序的文档编号列表，无结果返回[]
    """
    if not word:  # 空字符串直接返回空
        return []
    word = word.lower()  # 统一小写
    return inverted_index.get(word, [])
